# KOMI Report V5.2.8 — คู่มือผู้ใช้งาน

สถานะเอกสาร: Customer Review · อัปเดต 31 สิงหาคม 2569

> **สถานะชุดติดตั้ง V5.2.8:** ชุดติดตั้งที่ไม่มี Authenticode/Developer ID ต้องแสดงว่าเป็น **UNSIGNED INSTALLATION CANDIDATE** ผู้ใช้ต้องตรวจ SHA-256 กับ `CHECKSUMS.sha256` ก่อนติดตั้ง Windows อาจแสดง Unknown Publisher และ Smart App Control อาจบล็อกโดยไม่มี Run anyway; macOS Gatekeeper อาจปฏิเสธแอปที่ไม่ notarized หากระบบปฏิเสธให้หยุดและติดต่อผู้ส่งมอบ/ฝ่าย IT ห้ามปิดหรือหลบระบบความปลอดภัย รายละเอียดอยู่ใน `CUSTOMER_INSTALL_GUIDE.md`

## 1. ภาพรวม

KOMI Report ใช้อ่าน Total Meter และ Counter จากเครื่องพิมพ์ Konica Minolta ที่เลือกไว้ไม่เกิน 3 เครื่อง เก็บข้อมูลไว้ใน Database ของลูกค้า สร้างรายงาน Print/Copy และส่งออก Excel ได้

เมนูหลักมี 5 ส่วน:

1. **ภาพรวม** — ยอดใช้งาน ค่าใช้จ่าย และสถานะเครื่อง
2. **อุปกรณ์** — อ่านข้อมูลสด Total Meter หมึก ถาดกระดาษ และ Counter
3. **รายงาน** — Overview, Users, Printers, Usage และ Legacy
4. **ตั้งค่า** — เครื่องพิมพ์ ราคา รอบบิล ตารางอ่านข้อมูล และการตั้งค่าขั้นสูง
5. **คู่มือ** — คำแนะนำที่เปิดดูได้ภายในโปรแกรม

## 2. ติดตั้งเครื่อง Primary

1. กรอกชื่อบริษัท วันที่เริ่มใช้งานและ Version จะแสดงอัตโนมัติ
2. ตรวจ Database Path แล้วเลือก **Browse** เมื่อต้องการเปลี่ยนตำแหน่ง หรือ **Import** เมื่อต้องการใช้ฐานข้อมูลเดิม
3. อ่านประกาศข้อมูลการลงทะเบียน แล้วเริ่มค้นหาเครื่องพิมพ์ใน LAN
4. เลือกเครื่องพิมพ์ไม่เกิน 3 เครื่อง ตรวจ Model, Serial Number และ Web Connection
5. กำหนด Slot และชื่อจุดติดตั้ง
6. ตั้งราคา A4/A3 สีและขาวดำ วันตัดรอบบิล และเปอร์เซ็นต์กระดาษเสีย
7. ตรวจสอบข้อมูล แล้วกด **บันทึกและเปิดโปรแกรม**
8. รอ Online Registration สำเร็จ หาก Host ติดต่อไม่ได้ ให้ตรวจ Internet และการตั้งค่า แล้วกดลองใหม่

ระหว่างสแกน โปรแกรมแสดง Progress bar และจำนวน IP ที่ตรวจแล้ว กด Enter ในหน้ากำหนดช่วง IP เพื่อเริ่มสแกนได้

## 3. ติดตั้งเครื่อง Secondary

เมื่อพบ Primary ใน LAN โปรแกรมจะแสดงข้อมูลบริษัท เครื่องพิมพ์ ราคา และรอบบิลให้ตรวจสอบ ก่อน Sync ให้ผู้ใช้บน Primary เปิด **การตั้งค่าขั้นสูง → รายงานผ่าน LAN** แล้วกด **อนุญาต Secondary Sync 5 นาที** จากนั้น Secondary จึงดึงค่าได้โดยไม่ต้องกรอกรหัส Sync หากไม่ต้องการใช้ค่าที่พบ ให้ยกเลิกแล้วตั้งค่าใหม่ตาม Wizard ปกติ

Primary และ Secondary เปิดพร้อมกันได้ และ Web Report แบบอ่านอย่างเดียวยังคงเปิดจากเครื่องอื่นใน LAN ได้

## 4. หน้าอุปกรณ์

กด **อ่านข้อมูลตอนนี้** เพื่ออ่านเครื่องที่เลือกทันที การ์ดแต่ละเครื่องแสดงข้อมูลเท่าที่รุ่นนั้นรองรับ:

- Model และ Serial Number
- Total Meter และเวลาอ่านล่าสุด
- ระดับหมึก C/M/Y/K
- ถาดกระดาษ ขนาด/ชนิดกระดาษ และสถานะ Ready, Near Empty หรือ Empty
- Counter รายละเอียดจากเครื่อง
- User Authentication / Account Track เมื่อเปิดใช้ที่เครื่อง

เครื่องหมาย `—` หมายถึงเครื่องรุ่นนั้นไม่ส่งค่า หรือยังอ่านค่าไม่ได้ ไม่ใช่ค่า 0

การอ่านหลายรุ่นใช้ Targeted SNMP เป็นฐาน แล้วเลือก Web ตาม Profile ของเครื่องตามลำดับ **Modern JSON → Legacy Public XML → Legacy Admin XML เฉพาะเมื่อจำเป็น** การรองรับ TLS เก่าจะเปิดเฉพาะ Profile ของเครื่องนั้น ไม่ลดความปลอดภัยของเครื่องอื่นพร้อมกัน

## 5. รายงาน

เลือกวันที่เริ่มต้นและวันที่สิ้นสุดจากคนละช่อง แล้วใช้ช่วงเดียวกันกับทุกแท็บ

### Overview

สรุป Print สี/ขาวดำ, Copy สี/ขาวดำ, ยอดรวม และค่าใช้จ่าย พร้อมกราฟแนวโน้ม

### Users

แสดงผู้ใช้หรือ Account แยกตามเครื่องและประเภทงานที่เครื่องส่งมา หากเครื่องไม่ได้เปิด User Authentication/Account Track จะไม่มีข้อมูลผู้ใช้

### Printers

กราฟแสดงทุกเครื่องพร้อมกัน การเลือกแถวเครื่องจะเปลี่ยนเฉพาะรายละเอียด Meter

### Usage

เลือกมุมมอง D/M/Y และดูรวมทุกเครื่องหรือแยกตามเครื่อง หัวตารางแยก Print/Copy และ A3/A4 สี ขาวดำ และ Other

แถวแรกคือ **Meter เริ่มต้น** ใช้เป็นฐานอ้างอิงเท่านั้น ไม่รวมในยอดใช้งาน ยอดรวม หรือค่าใช้จ่าย

checkbox **คิดรวม % กระดาษเสีย** เปิดเป็นค่าเริ่มต้น ปิดได้เพื่อดูค่าใช้จ่ายก่อนส่วนลด โดยจำนวนหน้าไม่เปลี่ยน

### Legacy

แสดงชื่อ Counter ตามที่เครื่องส่งจริง เช่น A5, Large Size หรือ FAX โดยไม่บังคับ Map เป็น A3/A4 ใช้ตรวจสอบข้อมูลเฉพาะรุ่นและตรวจ Mapping

### Excel

กด **ส่งออก Excel** แล้วเลือกช่วงวันที่ ไฟล์มี 6 ชีท:

1. การใช้งานรายเครื่อง
2. มุมมองผู้ใช้
3. มุมมองรายวัน
4. Legacy-รายเครื่อง
5. Legacy-ผู้ใช้
6. Legacy-รายวัน

## 6. การตั้งค่า

หน้า Settings หลักใช้ตั้งเครื่องพิมพ์ ราคา รอบบิล ตารางอ่านข้อมูล และดูสถานะการลงทะเบียน

กด **เปิดการตั้งค่าขั้นสูง** เพื่อแสดงข้อมูลในหน้าเดิม:

- Database Path, Backup, Restore และตรวจความสมบูรณ์
- Auto-start, System Tray และพฤติกรรมเมื่อปิดหน้าต่าง
- เปิด/ส่งออก/ล้าง Log และล้างไฟล์ชั่วคราว
- Web Report บน LAN และตัวเลือกอ่านอย่างเดียวโดยไม่ใช้รหัส
- Parser Mapping
- คำสั่งล้างข้อมูลหรือเริ่มตั้งค่าใหม่

คำสั่งที่ลบหรือเขียนทับข้อมูลจะแสดงหน้าต่างยืนยัน ควร Backup Database ก่อน Restore เปลี่ยน Path หรือลบ Database

## 7. Parser Mapping

เปิด Parser Mapping จากการตั้งค่าขั้นสูง เลือก Slot แล้วเปรียบเทียบ Raw Data กับช่อง Database แก้เฉพาะรายการที่ Map ผิด และบันทึกแยกตาม Serial Number

ถ้าไม่แน่ใจ ให้เลือก **No Mapping** เพื่อเก็บข้อมูลต้นทางไว้โดยไม่รวมเข้าหมวดมาตรฐานผิดประเภท

## 8. Web Report บน LAN

Web Report เปิดให้อัตโนมัติและแสดง URL สำหรับเครื่องอื่นใน LAN สามารถอนุญาตให้ดูรายงานแบบอ่านอย่างเดียวโดยไม่ใช้รหัสได้ สิทธิ์เจ้าหน้าที่และการแก้ไขยังคงต้องยืนยันตัวตน

ควรเปิดโหมดไม่ใช้รหัสเฉพาะ **Trusted LAN** เพราะผู้ที่อยู่ใน LAN เดียวกันอาจเห็นรายงาน ชื่อผู้ใช้ในรายงาน และตัวระบุเครื่องพิมพ์ ห้ามเปิด Web Report ออก Public Internet

## 9. Online Registration

Online Registration เป็นวิธีปกติและทำงานก่อนเปิดหน้าหลักครั้งแรก หลังลงทะเบียน โปรแกรมส่งสถานะตามรอบพร้อม Total Meter รวมของเครื่องที่เลือก

Offline Activation ถูกปิดชั่วคราวใน V5.2.8 และไม่มีปุ่มส่งออก `.komirequest` หรือนำเข้า `.komilicense` ใน Wizard และ Settings การเปิดใช้งานครั้งแรกจึงต้องเชื่อม Internet เพื่อลงทะเบียน Online

## 10. การอัปเดตโปรแกรม

V5.2.8 ไม่มีระบบ Update อัตโนมัติ, Forced Update หรือ Remote Command เมื่อได้รับรุ่นใหม่ ให้ Exit โปรแกรม สร้าง Backup Database ตรวจ SHA-256 และติดตั้งด้วยไฟล์ชุดใหม่ที่ผู้ส่งมอบอนุมัติ

## 11. ปิดโปรแกรมและแก้ปัญหาเบื้องต้น

- กดปิดหน้าต่าง: โปรแกรมอาจทำงานต่อใน System Tray
- ต้องการเปิดใหม่: คลิกไอคอน KOMI Report ใน System Tray
- ต้องการหยุดจริง: เลือก **Exit / ออกจากโปรแกรม** จากเมนู System Tray
- ข้อมูลไม่อัปเดต: ตรวจเวลาอ่านล่าสุด แล้วกด **อ่านข้อมูลตอนนี้**
- เปิด Web ไม่ได้: ตรวจ URL และ LAN ในการตั้งค่าขั้นสูง
- ยอดไม่ตรง: ตรวจ Legacy และ Parser Mapping ก่อนเปลี่ยน Mapping
- ก่อน Restore หรือลบ Database: Exit โปรแกรมและสร้าง Backup
