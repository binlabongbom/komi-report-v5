## ขอบเขตที่ยังไม่ครอบคลุม

Fixture มี **Total หนึ่ง counter ต่อผู้ใช้ต่อเครื่องต่อวัน** ไม่ใช่ทุก counter แยก Print/Copy/A3/A4/Color/B&W/Scan จึงไม่ใช่ผลรับรองภาระสูงสุดของรายละเอียดครบทุกหมวด โดยเฉพาะการคำนวณต้นทุนผู้ใช้

ไม่มี Raw ระดับเครื่องใน fixture ทำให้ Legacy รายเครื่องและ Legacy รายวันแสดงรายการว่างตามข้อมูลต้นทาง แม้ยังผ่านการเลือกและสร้างทั้งสองชีต ไม่ได้ทดสอบข้อมูลเต็มของทุกชีต หรือประวัติ Web ทุกครั้งที่อ่าน

ประวัติทั้งหมดอยู่ในฐานหลักจำลอง ยังไม่ได้วัดข้อมูลที่ย้ายไป archive หลายไฟล์, ความเร็ว LAN/เครื่องพิมพ์, การเปิดไฟล์ใน Excel หรือการ Export พร้อมเปลี่ยนช่วงรายงานไปมาจริง
