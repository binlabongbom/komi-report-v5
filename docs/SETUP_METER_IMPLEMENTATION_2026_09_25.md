# ขั้นมิเตอร์เริ่มต้นใน Wizard จริง — 25 กันยายน 2569

ลำดับ: องค์กร → เครื่องพิมพ์ → มิเตอร์เริ่มต้น → ราคา → ตรวจสอบ.
ใช้หน้าราคาเดิมเพียงแห่งเดียว และใช้ component หน้ามิเตอร์ร่วมกับ Wizard จริง.

## พฤติกรรม

- เลือกตรวจได้ครบ 3 Slot; ตารางค่าจาก Meter แสดงชื่อและ source path จากผลอ่าน
  และตารางค่าหลัง Parser แสดง canonical field รวมการจับคู่ที่ตั้งไว้.
  คลิกที่มาของค่า Parser เพื่อดูแถวต้นทางได้.
- เครื่องใหม่ต้องมีผลอ่าน Web ที่ผ่านการตรวจ Counter/ผลรวมและ Serial จากการทดสอบครั้งนี้
  พร้อมกดยืนยันแต่ละ Slot. เปลี่ยนเครื่องจริงใช้ขั้นตรวจฐานใหม่โดยรักษายอดเครื่องเดิม.
- แก้ชื่อ/ราคา/เครือข่ายเครื่องเดิมที่มีฐานหรือประวัติแล้วข้ามขั้นยืนยันฐานใหม่.
  ฐานรุ่นเก่าที่ไม่มี epoch ใหม่ไม่ถูกรีเซ็ตหรือบังคับตั้งต้นใหม่.
- กรณี Slot 3 ถูกเพิ่มไว้แล้วแต่มีแค่ข้อมูล SNMP และยังไม่มี Web/history/epoch
  จะเข้าตารางยืนยันฐาน เพื่อแก้สาเหตุที่ระบบอ่านร่วมปฏิเสธก่อนอ่าน Web.
- ผลอ่านผูกกับ Slot/IP/Serial/บัญชี/TLS; ผลเก่าเกิน 30 นาทีและผลจากการทดสอบ
  ก่อนเปลี่ยนข้อมูลเชื่อมต่อใช้ยืนยันไม่ได้. ย้อนกลับหรือเปลี่ยนขั้นไม่บันทึกฐานจริง.
- กดบันทึกขั้นสุดท้ายจึงบันทึกเครื่อง ราคา การตั้งค่า ผลอ่าน epoch และ outbox
  ใน transaction เดียว; ล้มเหลวระหว่างทางย้อนกลับทั้งชุด.
- เก็บหลักฐานผลอ่านต้นฉบับเป็นฐาน journal/epoch; Parser view และ DailyCache
  ใช้ mapping เดียวกัน. ไม่มีการนำยอด Scan มารวม Total Meter หรือสร้าง A4/A3 เทียม.
- อ่านครั้งถัดไปนับจากฐานที่ยืนยัน: 2,475 → 2,480 = 5 หน้า;
  → 2,483 = 8 หน้า. อ่านซ้ำ/เปิดใหม่ไม่บวกซ้ำ และวันใหม่ใช้ยอดปิดก่อนหน้า.

## การทดสอบ

- Component: 3 Slot, ต้องยืนยันเฉพาะเครื่องใหม่, เปลี่ยนผลอ่านต้องยืนยันใหม่,
  สลับ Meter/Parser และกดดูต้นทาง, ยุบ/ขยายหน้าต่าง.
- Wizard จริง: 5 ขั้น, ราคาแห่งเดียว, กลับไปแก้ฐานจากหน้าสรุป,
  กดบันทึกโดยไม่ยืนยันไม่ได้, แก้ credentials แล้วไม่รับผลทดสอบเก่า,
  เปลี่ยนที่เก็บฐานข้อมูลครั้งแรก, รองรับภาษาไทย/อังกฤษ.
- Persistence: rollback กรณีเสียระหว่าง observation/epoch/settings,
  ไม่ทับ Slot เดิม, ผลอ่านหมดอายุ/เปลี่ยน identity, รักษา last_success_at รุ่นเก่า.
- Polling จริงกับ Probe/Reader จำลอง: DailyCache, Raw Counter, User,
  Parser mapping, อ่านซ้ำ, เปิดใหม่ และเปลี่ยนวัน.

  อ่านต่อแบบผูก epoch ได้ 5 หน้า และเอกสารฐาน Slot 1–2 คงเดิม.
