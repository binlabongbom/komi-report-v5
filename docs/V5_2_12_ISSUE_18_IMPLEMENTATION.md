## ผลตรวจ source

- **269 กรณีผ่าน เมื่อรวมผลล่าสุดของแต่ละกรณี** ใน qa/v5.2.12/issue-18/tests.json
  รอบรวมจบที่ 204 passed / 2 failed: หนึ่งข้อคาดสี disabled เดิม และ benchmark Export
  ที่ปนการสร้าง/ทำลายหน้าต่างจำนวนมากจากชุดทดสอบก่อนหน้า
  ปรับ expectation ตามสีใหม่ และให้ benchmark ใช้ QApplication ในโปรเซสใหม่พร้อมธีมจริง
  โดยคง workload, timer/click ceiling, ตรวจ Workbook และเงื่อนไขกันงานซ้อนเดิม
  ชุดตรวจซ้ำ 25 passed; หลังแก้ภาษา Wizard/สถานะตารางและป้องกันชื่อข้อมูล อีก 81 passed;
  ตรวจคู่มือ/controls/ภาษาในรอบท้าย 13 passed (นับกรณีซ้ำครั้งเดียว)
- Benchmark นี้ตรวจการตอบสนองในสภาพเริ่มใหม่ ไม่ใช่หลักฐานว่าทุก session
  หลังใช้งานนานจะไม่มีการหน่วง การวัดระยะยาวและ Windows จริงยังอยู่ในแผน Performance/หลัง build
- Web export มี 17 กรณี รวมการยกเลิกระหว่างเตรียม/เขียน/ก่อนเปลี่ยนไฟล์ปลายทาง
  ไฟล์เดิมอยู่ครบเมื่อยกเลิกหรือล้มเหลว; ปิดหน้าหลักฐานแล้ว worker ได้รับ cancellation
  สิทธิ์และพื้นที่ไม่พอใช้ fault injection ไม่ทำดิสก์หรือสิทธิ์เครื่องจริงเสียหาย
- ตรวจ PDF จริงทุกช่วงเวลา: 960 จุด → 959 ช่วง / 30 วัน รวม 959 หน้าพิมพ์;
  4,096 จุด → 4,095 ช่วง / 128 วัน รวม 4,095 หน้าพิมพ์ ทั้งตารางและกราฟรายวันตรงกัน
  PDF มี 62 / 264 หน้ากระดาษตามลำดับ ตรวจภาพหน้าแรก หน้าท้าย และข้อความครบทุกช่วง
- กรณีช่วงขาดเดิม 301 หน้า / 2 วันยังเป็น 150.5 ต่อวัน ไม่มีการบวกซ้ำ

  แก้ชื่อปุ่มให้สั้นพร้อม tooltip เต็ม ตรวจซ้ำได้ 900×600 จริง
  เครื่องมือ audit จะ fail หาก MainWindow ขยายเกินขนาดที่ร้องขอ

- เก็บ 265 ภาพจาก 12 ชุดตรวจ (รวมสถานะ/ขนาดซ้ำ ไม่ใช่หน้าจออิสระ) พร้อมภาพตัวแทน 19 ภาพ
  และภาพตรวจ PDF หน้าแรก/ท้าย แก้สรุป Wizard เป็น template ก่อนใส่ชื่อบริษัท/เครื่องพิมพ์
  และระบุชัดว่าช่องสถานะ/ตัวเลือกใดเป็น UI ที่แปลได้โดยไม่แปลชื่อข้อมูล

## การแก้ต่อความเสถียร

Web evidence ใช้ bound methods แทน signal lambdas ที่จับตัว dialog และยุติ export เมื่อปิดหน้าต่าง
PDF แบ่งจัดหน้าชุดละ 48 แถวเพื่อให้มีจังหวะตรวจ cancellation และอัปเดต progress
Reports Excel คืนเวลาสั้น ๆ ระหว่าง checkpoint ของงาน CPU โดยไม่เปลี่ยนสูตร/แถว/ราคา
Legacy translation ใช้ regex ที่ compile ครั้งเดียวแทนการวนหลายร้อยครั้งต่อ label

แก้ import ของ field label ที่ขาดซึ่งทำให้ dialog สร้างไม่ครบ และตรวจซ้ำแล้ว
รอบรวมล่าสุดจบครบโดยไม่มี native crash ข้อทดสอบสี/เวลาที่ไม่ผ่านแก้ตามที่แจกแจงข้างต้น
Harness เก็บภาพทำลาย native windows ใน Qt event loop ก่อนจบ interpreter
หลังพบการจบ harness ผิดพลาดหลังบันทึกภาพครบ; รอบตรวจซ้ำจบสำเร็จ
