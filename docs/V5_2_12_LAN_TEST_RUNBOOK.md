# 5.2.12 - ขั้นตอนทดสอบสมาชิกและยอดบัญชี

วันที่ 22 กันยายน 2569 เอกสารสำหรับทดสอบ source และเตรียมรอบเครื่องจริง + VM105
ยังไม่ใช่ผลผ่านการติดตั้งจริง: ต้องใช้แพ็กเกจที่สร้างจาก source ชุดนี้ทั้งสองเครื่อง
ไฟล์ติดตั้งเดิม 5.2.10/5.2.11 ไม่ได้รวมการเปลี่ยนแปลงนี้

## ขอบเขตที่ตกลง

- เครื่องติดตั้งใหม่อาจไม่พบกลุ่มเดิม ทีมติดตั้งช่วยค้นหา/กรอก IP ได้
- ถ้ากุญแจหายถาวร ใช้สมาชิกใหม่ในฐานใหม่ เก็บฐานและ Archive เดิมไว้
  ไม่ปลอมตัวเป็นสมาชิกเดิมหรือรวมบัญชีเดิมอัตโนมัติ
- ไม่แก้ Host และไม่ข้ามการลงทะเบียน Online/Offline ตามปกติ
- บัญชีใหม่จากประวัติร่วมต้องมีผู้ตรวจและยืนยัน รายการปิดแล้วใช้ฉบับแก้ไขเดิม
  การ Sync หลักฐานไม่ได้เท่ากับการอนุมัติยอดบัญชีทุกเครื่องโดยอัตโนมัติ

## เตรียมรอบทดสอบ

1. ใช้บริษัท/เครื่องพิมพ์/ฐานข้อมูลทดสอบ สำรองฐานและ Archive ก่อนเริ่ม
2. ใช้ source หรือแพ็กเกจรุ่นเดียวกันที่มีชุดแก้นี้ บันทึก commit/วันที่ build
3. เปิดรายงานผ่าน LAN บนต้นทาง และตรวจว่าอีกเครื่องเข้าถึง HTTPS ที่พอร์ตที่ตั้งไว้ได้
4. ให้ทีมติดตั้งตรวจ Windows Firewall: HTTPS ตามพอร์ตจริง (ค่าเริ่มต้น TCP 3000),
   TCP 37853 สำหรับสมาชิก, UDP 37852 สำหรับค้นหาใน LAN ให้จำกัดโปรแกรม/เครือข่ายที่ทดสอบ
   `tools/lan_test_preflight.ps1` เป็นเครื่องมือตรวจอย่างเดียว ไม่แก้กฎ Firewall
5. ลงทะเบียนเครื่องต้นทางตามปกติ และอ่าน Web ทุก Slot เมื่อเข้าร่วมครั้งแรก ระบบสร้างฐานเริ่มต้นอัตโนมัติจากข้อมูลที่ตรวจ Serial, ผลรวม และความต่อเนื่องแล้ว หากไม่มีผลอ่านหรือพบข้อมูลขัดแย้ง ระบบแจ้ง Slot ที่ต้องแก้ ไม่สร้างฐานทดแทน/reset อัตโนมัติ

## A. เพิ่มสมาชิกจากฐานว่าง

1. ต้นทาง: เปิด Desktop/Agent แล้วตรวจสถานะ **เปิดตลอด** ในการตั้งค่าเครือข่าย
   ค่าเริ่มต้นเปิดรับสมาชิกอัตโนมัติ ไม่ต้องกดอนุญาตแต่ละครั้ง และจำค่าหลังเปิดโปรแกรมใหม่
2. เครื่องใหม่: เปิด Wizard เลือกตำแหน่งฐานข้อมูล ค้นหา/กรอก IP ต้นทาง
   ตรวจบริษัทและเครื่องพิมพ์ แล้วเลือก **เข้าร่วมและใช้การตั้งค่าร่วมกัน**
3. ตรวจเครื่องพิมพ์จากเครื่องใหม่นี้ กรอกรหัสเครื่องพิมพ์เองหากจำเป็น
   ราคาและประวัติฐานมิเตอร์ต้องตรงกับกลุ่ม ราคาปรับภายหลังได้ที่การตั้งค่าร่วม
4. กดบันทึกและลงทะเบียนเครื่องใหม่ตามปกติ ต้องมี Installation ID คนละค่า
5. ดูสถานะเครือข่าย: ทั้งคู่รับส่งครบ ประวัติการตั้งค่าและฐาน Slot ตรงกัน
6. เปลี่ยนค่าร่วมหนึ่งรายการโดยยืนยัน จากนั้นตรวจอีกเครื่องว่าได้รับค่าและมีประวัติ

ผลที่ต้องได้: ไม่มีรหัสเครื่องพิมพ์/สิทธิ์ Host ถูกคัดลอก ไม่มีประวัติราคาชุดใหม่แทนประวัติเดิม
ยกเลิกก่อนบันทึกต้องไม่มีสมาชิกหรือเครื่องพิมพ์ใหม่ในฐานใช้งาน

## B. การอ่านและการขาดการเชื่อมต่อ

- กดอ่านจากสองเครื่องใกล้กัน ต้องเห็นผล Web ชุดเดียวกันและไม่เพิ่มยอดซ้ำ
- ปิดหนึ่งเครื่อง ให้อีกเครื่องทำงานต่อ เปิดกลับมาแล้วกดค้นหาและเชื่อมต่อสมาชิกเดิม
  ตรวจว่าเติมหลักฐานครบ การส่งซ้ำไม่เพิ่มยอดหรือจำนวนตัวอย่าง
- หากมีเครื่องที่สาม ให้ทั้งสองสมาชิกเรียนรู้รายชื่อกันก่อนปิดต้นทาง
  ทดสอบส่งข้อมูลกันต่อโดยไม่ต้องเปิดต้นทางที่ใช้เพิ่มสมาชิก
- ปิดการอนุญาตระหว่างเข้าร่วม ต้องไม่แสดงว่าการเชื่อมครบ หากบันทึกสมาชิกในเครื่องแล้ว
  ลงทะเบียนต่อได้ แต่สถานะเครือข่ายต้องบอก **เข้ากลุ่มยังไม่ครบ**
  ถ้าทดสอบโดยปิดสิทธิ์เอง ให้เปิดตลอดกลับหนึ่งครั้ง แล้วกดค้นหาและเชื่อมต่ออีกครั้ง
  กรณีคำขอหมดอายุให้ต่ออายุอัตโนมัติ ไม่ต้องให้ผู้ใช้กดเปิดรับใหม่ ไม่สร้างสมาชิกซ้ำ

## C. กุญแจหายถาวร

ใช้ฐานและบัญชี OS ทดสอบสำหรับจำลอง ห้ามลบกุญแจจริงเพื่อทดสอบ

1. เปิดฐานที่คืนมาบนเครื่องทดสอบซึ่งไม่มี vault เดิม ต้องแจ้งกุญแจหายและหยุดเชื่อม
2. เมื่อทีมติดตั้งยืนยันว่ากู้ไม่ได้ เลือก **เริ่มสมาชิกใหม่โดยเก็บฐานเดิม**
3. เลือกชื่อฐานใหม่ กดสร้าง ตรวจตำแหน่ง แล้วกด **ใช้ฐานใหม่และปิดโปรแกรม**
4. เปิดโปรแกรมใหม่ ทำ Wizard และลงทะเบียนใหม่ ใช้ขั้นตอน A เพื่อเข้ากลุ่ม
5. ตรวจฐานเดิมยังอยู่ ฐานใหม่ใช้ Installation ID ใหม่ ไม่รับบัญชี/Host token เดิม

การเปลี่ยนฐานไม่ได้ย้าย Archive/เอกสารเก่าเข้าฐานใหม่หรือเพิกถอนสมาชิกเก่าทุกเครื่อง
ให้ทีมติดตั้งเก็บเครื่องเก่าที่เลิกใช้ไว้นอกการทดสอบ และจัดการสิทธิ์สมาชิกเดิมตามกระบวนการดูแล

## D. ตรวจยอดจากประวัติร่วม

1. หน้าตรวจรอบบิล กด **ตรวจยอดจากประวัติร่วมก่อนลงบัญชี**
2. เลือก Slot และช่วงวัน (ไม่เกิน 93 วัน) กดตรวจยอด
3. ตรวจวันที่ จำนวนหน้า ยอดสุทธิ และวันรอตรวจ กรอกเหตุผล แล้วกดยืนยันรายการที่พร้อม
4. ตรวจ Billing Ledger และรายงาน Usage ว่าหน้าและยอดตรงกัน กดยืนยันซ้ำต้องไม่เกิดบัญชีซ้ำ
5. วันที่มีบัญชี/ข้อมูลเดิมอยู่แล้วต้องรอตรวจฉบับแก้ไข ไม่สร้างบัญชีซ้อน
6. เปลี่ยนราคา/หลักฐานหลังเปิดตัวอย่างแล้วลองยืนยัน ต้องบังคับตรวจใหม่
7. ทดสอบวันที่ขาด Web: ไม่มีการสร้างเวลาหรือจำนวนครั้งอ่านปลอม และยอดรวมคงเดิม

## หลักฐานและเกณฑ์จบรอบ

บันทึกรุ่นทั้งสองเครื่อง, IP/พอร์ต, Installation ID, เวลาทดสอบ,
ภาพสถานะรับส่ง, ประวัติการตั้งค่า, จำนวน Web/ยอด Usage, Ledger และผลแต่ละข้อ
ห้ามใส่ private key, token หรือรหัสเครื่องพิมพ์ในหลักฐาน

ผ่านรอบเครื่องจริงเมื่อ A-D ผ่านตามขอบเขตที่ใช้จริง รวมรีสตาร์ต Desktop/Agent
และ Firewall ของแพ็กเกจ ทดสอบ source แบบ TLS loopback ไม่ใช้แทนผลรอบนี้
