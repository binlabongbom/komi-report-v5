## การตั้งค่าและประวัติ

1. ตั้งบริษัทจำลองและเครื่องพิมพ์ Slot 1–3 บันทึกแล้วเปิดประวัติจาก
   **การตั้งค่าเครือข่าย → ประวัติการตั้งค่าร่วม**
2. เปลี่ยนรอบบิล/ส่วนลด/ตารางอ่าน ตรวจค่าเดิม–ใหม่ในหน้าต่างยืนยัน
   กดยกเลิก: ค่าฐานข้อมูลต้องเดิม และแบบฟอร์มยังเก็บสิ่งที่พิมพ์ไว้
3. ยืนยันบันทึก: ค่าและประวัติต้องปรากฏพร้อมกัน เปิดใหม่ต้องไม่สูญหาย
4. ขณะเปิดหน้าต่างยืนยัน ให้กระบวนการจำลองอื่นแก้ค่าเดียวกัน
   กดยืนยันหน้าต่างเดิมต้องแจ้งให้ตรวจใหม่ ไม่เขียนทับค่าที่เพิ่งเปลี่ยน
5. เลือกรายการเก่า กด **ตรวจและย้อนค่า** ตรวจค่าเดิม–ใหม่ก่อนยืนยัน
   ต้องเพิ่มประวัติใหม่ และไม่ย้อนฟิลด์อื่นที่ไม่ได้อยู่ในการเปลี่ยนครั้งนั้น
6. จำลองประวัติจากคอมสองเครื่องที่แก้จากฐานเดียวกัน ให้มีรายการรอตรวจ
   เลือกค่าที่รับมาหรือคงค่าปัจจุบัน ยกเลิกต้องไม่เปลี่ยนค่า
   ยืนยันแล้วต้องเก็บที่มาทั้งสองฝั่ง ไม่เลือกเพราะนาฬิกาเครื่องใดใหม่กว่า

หน้าประวัติรองรับรอบบิล ส่วนลด ตารางอ่าน และประวัติราคาแบบมีวันบังคับใช้
การเปลี่ยนเครื่อง/ฐานมิเตอร์และบริษัทต้องเชื่อม workflow ของส่วนนั้นให้ครบตามแผน
การมีหน้าประวัติไม่ได้หมายความว่าคิวส่งตั้งค่าอัตโนมัติระหว่างคอมเสร็จแล้ว

## ราคาและการบันทึก Wizard

- กำหนดราคาเดิมวันที่ 1 กันยายน และราคาใหม่วันที่ 1 ตุลาคม
  ก่อนตุลาคมยังใช้ราคาเดิม แต่ประวัติร่วมต้องมีทั้งสองวัน
- ในหน้าต่างยืนยันต้องเห็นวันบังคับใช้และราคาที่เปลี่ยน
  ประวัติราคาที่ไม่ได้แก้ยังต้องอยู่ครบแม้ไม่แสดงซ้ำในหน้าต่างยืนยัน
- จำลองผิดพลาดหลังบันทึกเครื่องพิมพ์ ระหว่างเขียนราคา และระหว่างเขียนประวัติ
  ต้องย้อนคืนฐานข้อมูลและรหัสผ่านเดิม ไม่เหลือการบันทึกบางส่วน
- แก้เครื่องพิมพ์จาก Settings ต้องไม่เปลี่ยนรอบบิล/ส่วนลดที่ตั้งไว้
  และไม่ส่งลงทะเบียน Host แทรกระหว่างการแก้ไขนี้

## ค้นหาใน LAN

1. บนเครื่อง A เปิดบริการ Web ของ source พร้อมข้อมูลจำลองที่ตั้งค่าแล้ว
2. บน B เปิด Wizard แล้วค้นหา ระบบส่ง UDP ไปยัง broadcast ของวง LAN
   A ตอบพอร์ต HTTPS กลับ B โดยตรง ไม่มีราคา มิเตอร์ หรือรหัสผ่านใน UDP
3. B ต้องตรวจผ่าน HTTPS ก่อนแสดงเป็นเครื่องที่รับการตั้งค่าได้
   การพบเครื่องไม่ได้ยืนยันสิทธิ์บริษัทหรืออนุญาตให้รับข้อมูลทันที
4. ทดสอบไม่พบเครื่อง/พอร์ตชน/UDP ถูกบล็อก ปุ่ม **ค้นหาอีกครั้ง** ต้องใช้ได้
   และยังกรอก IP กับพอร์ตจริงได้ ไม่สรุปว่าในวงไม่มี KOMI
5. หยุดบริการ ต้องไม่มี thread discovery ค้าง เปิดใหม่ต้องไม่ตอบซ้ำหลาย process

การทดสอบอัตโนมัติปัจจุบันใช้ loopback ไม่ได้เปลี่ยน Firewall ของ Windows
การตรวจบนสองคอมจริงยังต้องทำหลังพร้อมสภาพแวดล้อมทดสอบ:
อนุญาต UDP 37852 และ HTTPS พอร์ตที่ใช้งานเฉพาะโปรแกรมเจ้าของ listener
เฉพาะ Private network/LocalSubnet ตรวจชื่อไฟล์และ PID จริงก่อนสร้างกฎ
อย่าปิด Firewall ทั้งระบบ และอย่าเปิดสิทธิ์เครือข่าย Public เพื่อให้ค้นพบ
