ภาพรวมการเก็บข้อมูล

ข้อมูลไหนอยู่ชั่วคราว ข้อมูลไหนรอดเมื่อปิดโปรแกรม และตารางไหนใช้กับ History / Billing

← กลับไปกฎการ Sync
แหล่งข้อมูล RAM ชั่วคราว JSON Daily Cache SQLite รายงาน
Daily Cache มีไว้กันข้อมูลหายเขียนแบบ atomic JSON แยกเครื่องและวัน จึงกลับมาทำต่อได้หลังเปิดโปรแกรมใหม่
Database ลดการบวมDevice Meter เก็บหนึ่ง record ต่อเครื่องต่อวัน และ User เก็บหนึ่ง record ต่อ User/เครื่อง/วัน
จุดที่ยังต้องทำต่อ`daily_meter_records` ปัจจุบัน upsert แถวเดิมได้ จึงยังไม่ใช่ Immutable Append-only Billing Ledger เต็มรูปแบบ
