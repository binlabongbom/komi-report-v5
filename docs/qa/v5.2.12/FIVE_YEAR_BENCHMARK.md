# จำลองข้อมูล 5 ปี / 100 ผู้ใช้

ทดสอบ source วันที่ 18 กันยายน 2569 ในฐานข้อมูลจำลองแยกจากข้อมูลลูกค้า
ใช้ schema 23, Windows/Python 3.14.7 บนเครื่องพัฒนานี้ ขณะมี source tests รันอยู่ด้วย
เวลาเป็นการวัด service query ไม่รวมเวลาเปิดโปรแกรม วาดหน้าจอ หรือเครือข่าย

## ข้อมูลที่เขียนจริง

- 18 กันยายน 2021 ถึง 17 กันยายน 2026 รวม 1,826 วัน ทุกวันมีข้อมูล
- เครื่องพิมพ์ 3 เครื่อง ใช้ผู้ใช้ชุดเดียวกัน 100 รายในแต่ละเครื่อง
- รายเครื่อง 5,478 แถว; Ledger 5,478 แถว
- ประวัติผู้ใช้ 547,800 แถว; Raw Counter ผู้ใช้ 547,800 แถว
- เก็บ Total ต่อผู้ใช้หนึ่งตัว ไม่ใช่ทุก Counter ที่เครื่องจริงอาจส่ง
- ยอดรวมตรวจสอบตรง 6,573,600 หน้า
- เขียน 81.84 วินาที; ฐานข้อมูลรายวัน **435,470,336 bytes ≈ 415.3 MiB**

## เวลาเรียกข้อมูล

| รายการ | ค่ากลาง 3 รอบ |
|---|---:|
| สรุปรายเครื่องทุกเดือนใน 5 ปี | 463.76 ms |
| รายงานผู้ใช้ 30 วัน ก่อนแก้ | 40,300.30 ms |
| รายงานผู้ใช้ 30 วัน หลังกรองวันที่ใน SQL | 523.41 ms |
| Raw Counter เฉพาะ 30 วัน | 738.10 ms |

รายงานผู้ใช้ก่อน–หลังคืน 300 กลุ่มเท่ากัน หลังแก้ตรวจยอด 108,000 หน้าตรงสูตรข้อมูลจำลอง
ตัวกรองเดิมอ่านและแปลงทั้ง 547,800 แถวก่อนกรอง หลังแก้อ่านเฉพาะ 9,000 แถวที่เลือก
เวลานี้ไม่ใช่คำรับประกันบนทุกเครื่อง และยังไม่ใช่ผลทดสอบ Archive

## ผล Web แต่ละรอบ — ประมาณการแยก

วัด payload จริงหนึ่งรอบของ 100 ผู้ใช้ได้ 22,976 bytes สมมติอ่าน 8 ชั่วโมง/วันทุกวัน
บน 3 เครื่องพิมพ์ตลอด 5 ปี ได้ค่าประมาณเนื้อหา JSON ดิบดังนี้:

| รอบอ่าน | JSON ดิบโดยประมาณ |
|---|---:|
| ทุก 5 นาที | 11.25 GiB |
| ทุก 15 นาที | 3.75 GiB |
| ทุก 30 นาที | 1.88 GiB |
| ทุก 60 นาที | 0.94 GiB |

ไม่ได้เขียนผล Web ครบ 5 ปีจริง ตัวเลขนี้ไม่รวม SQLite indexes/receipt,
Counter เพิ่มเติมของเครื่องจริง, backup และ overhead ของไฟล์
ลองบีบอัด payload เดียวได้ 1,644 bytes แต่ยังไม่ได้เปิด compression/archive ใน production
จึงไม่ใช้ผลบีบอัดนี้อ้างเป็นขนาดฐานข้อมูลจริง

## ทำซ้ำ

จากโฟลเดอร์ source ใช้ Python environment ของโครงการ:

```text
python tools/benchmark_five_years.py <โฟลเดอร์ใหม่สำหรับข้อมูลจำลอง>
```

เครื่องมือปฏิเสธโฟลเดอร์ที่มีอยู่แล้ว ตั้ง database path ก่อน init และคืน path เดิมเมื่อจบ
ไม่ใช้ฐานข้อมูลที่ตั้งค่าไว้และไม่เรียกเครื่องพิมพ์หรือ Host
หลักฐานตัวเลขอยู่ใน `five-year-baseline.json` และ `five-year-subject-query.json`

ยังต้องพัฒนา Archive เกิน 12 เดือน, สรุปเดือน, ตรวจไฟล์ก่อนย้ายรายละเอียด
และเปิดรายละเอียดเก่าเมื่อผู้ใช้เรียก รวมถึงวัดขนาด/เวลาหลัง Archive แยกอีกครั้ง
