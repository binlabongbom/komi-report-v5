ดูภาพการเก็บข้อมูล →
SNMP Web RAM Cache / DB เงื่อนไข
SNMP = ตรวจสถานะใช้ดู Online, Total และ Toner ไม่ใช้เป็นยอด Billing
Web = ยอดหลักCounter จาก Web Connection เท่านั้นที่ใช้คำนวณ Usage และค่าใช้จ่าย
RAM = ผู้ใช้งานใช้แสดง User Authentication / Account Track แยกจาก Billing
